# 🚗 CRM и сайт для автосервиса (Django)

Комплексная система для управления небольшим автосервисом. Проект включает в себя публичный лендинг для привлечения клиентов и внутреннюю CRM для владельца бизнеса.

## 🎯 Бизнес-задача
Автосервису требовалась система, которая автоматизирует приём заявок с сайта, ведёт учёт клиентов и автомобилей, помогает формировать заказ-наряды, отслеживать остатки на складе и распечатывать прайс-листы для клиентов.

## 🚀 Ключевые возможности

### Публичная часть (Сайт)
*   **Лендинг:** Адаптивная вёрстка, каталог услуг с ценами «от», интеграция статической карты с переходом в навигатор.
*   **Форма заявки:** Сбор имени и телефона. Жёсткая валидация номеров (только российские, нормализация в формат `+7XXXXXXXXXX`).
*   **Уведомления:** Мгновенная отправка новых заявок в личные сообщения ВКонтакте владельцу сервиса через VK API.

### CRM (Для владельца)
*   **Клиенты и Автомобили:** Связь «один ко многим». Валидация VIN (17 символов) и госномеров (по маске РФ).
*   **Заказ-наряды:** Учёт пробега (с валидацией, что новый пробег не меньше прошлого), выбор мастера, способа оплаты.
*   **Разделение позиций:** Отдельные таблицы для запчастей (с проверкой остатков на складе и ссылками на поставщиков) и для услуг (с автоподстановкой цены из справочника).
*   **Склад:** Учёт запчастей и расходников.
*   **История рекомендаций:** При создании нового заказа по авто система автоматически подтягивает заметки мастера из прошлых визитов.

### Админ-панель и Аналитика
*   Кастомный интерфейс на базе **Django Unfold** (тёмная/светлая тема, кастомные CSS-стили).
*   **Дашборд:** Финансовая статистика за период (выручка по запчастям и работам отдельно), фильтрация по мастерам и датам.
*   **Печать:** Генерация HTML-прайса для клиента через `@media print`. Группировка позиций.

## 🛠 Стек технологий
*   **Backend:** Python 3.12, Django 5.2
*   **Database:** SQLite (в разработке), PostgreSQL (в планах на деплой)
*   **Frontend:** HTML5, CSS3 (Grid/Flexbox), Vanilla JavaScript
*   **Admin Theme:** Django Unfold
*   **Integrations:** VK API (для уведомлений)

## 📂 Архитектура проекта
Проект разделён на логические приложения:
*   `core` — общие утилиты: кастомные поля, валидаторы, константы (справочники услуг и поставщиков), пагинация.
*   `public` — публичный сайт и форма заявок.
*   `crm` — внутренняя CRM (модели клиентов, авто, заказов, склада).
*   `notifications` — интеграция с внешними API (ВКонтакте).

## ⚙️ Установка и запуск (локально)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Albert-Galimov/svoi_service.git
   cd название-репозитория

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv

3. **Активируйте виртуальное окружение:**
   ```bash
   source venv/Scripts/activate

4. **Активируйте виртуальное окружение:**
   ```bash
   pip install -r requirements.txt

5. **Настройте переменные окружения:**
Создайте файл .env в корневой папке проекта (рядом с manage.py). Скопируйте туда содержимое из .env.example и заполните своими данными:
   DJANGO_SECRET_KEY=ваш_секретный_ключ
   VK_GROUP_TOKEN=токен_вашего_сообщества
   VK_OWNER_ID=ваш_id_вк

6. **Примените миграции для создания базы данных:**
   ```bash
   python manage.py migrate

7. **Создайте суперпользователя для входа в админку:**
   ```bash
   python manage.py createsuperuser

8. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver

После этого сайт будет доступен по адресу http://127.0.0.1:8000/, а админка — http://127.0.0.1:8000/admin/.
